# Invest News Bot

Telegram-бот для мониторинга финансовых новостей. Получает публикации из российских и зарубежных RSS-источников, оценивает тональность и значимость, формирует тематические сводки, прогнозы по новостному фону и персональные уведомления.

## Возможности

- `/latest [N]` — показать от одной до десяти свежих новостей с оценкой тональности и значимости;
- `/analyze <тема>` — найти новости по теме и сформировать краткую сводку;
- `/forecast <тема>` — оценить новостной фон и показать направление, горизонт и ключевые факторы;
- `/watch <тема>` — подписаться на значимые новости;
- `/unwatch <тема>` — удалить подписку;
- `/watchlist` — показать и изменить подписки;
- `/digest` — включить или выключить ежедневный утренний дайджест;
- `/sources` — показать источники новостей.

Основные действия доступны не только командами, но и через кнопки интерфейса. Зарубежные заголовки и описания переводятся на русский язык. Длинные ответы автоматически разбиваются на несколько сообщений Telegram.

## Источники новостей

РБК Экономика, Коммерсантъ Деньги, Интерфакс, ТАСС Экономика, Ведомости, CNBC, MarketWatch, Financial Times и Investing.com.

Список и адреса RSS-лент находятся в `sources.py`. Доступность конкретных лент зависит от внешних сайтов.

## Технологии

- Python 3.10+;
- aiogram 3;
- SQLite;
- стандартные `urllib` и `xml.etree.ElementTree` для RSS;
- опционально OpenAI-совместимый API для более подробного анализа.

## Установка и запуск

```bash
git clone https://github.com/Kratos31071992/invest-news-bot.git
cd invest-news-bot
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
cp .env.example .env
```

Создайте бота через `@BotFather` и укажите полученный токен в `.env`:

```dotenv
BOT_TOKEN=your_telegram_bot_token
ALERT_INTERVAL_SEC=900
DIGEST_TIME=09:00
```

После настройки запустите:

```bash
python3 bot.py
```

Для Windows активация виртуального окружения:

```powershell
.venv\Scripts\Activate.ps1
```

## Дополнительный LLM-анализ

Без API-ключа бот использует локальный анализ новостей. Для более подробных разборов установите пакет `openai` и добавьте настройки в `.env`:

```bash
python3 -m pip install openai
```

```dotenv
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4o-mini
# OPENAI_BASE_URL=https://example.com/v1
```

`OPENAI_BASE_URL` нужен только при использовании другого OpenAI-совместимого сервиса.

## Хранение данных

Подписки, настройки дайджеста, обработанные ссылки и кэш переводов сохраняются в SQLite. Локально создаётся файл `bot_data.sqlite3` рядом с кодом. Если в системе существует каталог `/data`, база размещается там для сохранения между перезапусками контейнера.

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Команды, кнопки, уведомления, прогнозы и дайджесты |
| `sources.py` | Загрузка, фильтрация и поиск новостей |
| `analyzer.py` | Тональность, значимость, сводки и прогнозы |
| `translator.py` | Перевод и кэширование переводов |
| `storage.py` | Хранение данных в SQLite |
| `config.py` | Чтение настроек и проверка токена |
| `amvera.yaml` | Конфигурация развёртывания |

## Ограничения

- Результат зависит от доступности RSS-лент и качества опубликованных данных.
- Автоматическая тональность и прогноз описывают новостной фон, а не гарантированное движение цены.
- Сводки и прогнозы не являются инвестиционными рекомендациями.
- Для круглосуточных уведомлений процесс бота должен постоянно работать на компьютере или сервере.
