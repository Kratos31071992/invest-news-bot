# 📊 Инвест-бот: анализ рынка по новостям

Телеграм-бот, который читает новости из нескольких финансовых источников,
оценивает их тональность и значимость для рынка и присылает аналитические сводки.

## Возможности

- **`/latest [N]`** — N свежих новостей с оценкой тональности (🟢 бычья / 🔴 медвежья / ⚪ нейтральная) и значимости (★)
- **`/analyze <тема>`** — разбор всех свежих новостей по теме: `/analyze нефть`, `/analyze SBER`, `/analyze ставка`
- **`/watch <тема>`** — подписка: бот сам пришлёт алерт, когда выйдет значимая новость по теме
- **`/unwatch`, `/watchlist`** — управление подписками
- **`/sources`** — список источников
- **LLM-режим** (опционально): если задан `OPENAI_API_KEY`, `/analyze` даёт глубокий разбор через GPT вместо простой сводки

## Источники новостей

РБК Экономика · Коммерсантъ Деньги · Интерфакс · CNBC · MarketWatch · FT · Investing.com

Добавить свой источник — одна строка в словаре `RSS_SOURCES` в `sources.py`.

## Запуск

```bash
# 1. Создайте бота у @BotFather в Telegram, получите токен

# 2. Установите зависимости (лучше в venv)
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt

# 3. Настройте конфиг
cp .env.example .env
# впишите BOT_TOKEN в .env

# 4. Запустите
./.venv/bin/python bot.py
```

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | команды бота и фоновые алерты (aiogram 3) |
| `sources.py` | загрузка RSS-лент, поиск по новостям |
| `analyzer.py` | анализ тональности + опциональный LLM-разбор |
| `storage.py` | подписки и история в SQLite |
| `config.py` | токен и настройки из `.env` |

## Что можно добавить дальше
